# bob_sessions

Required by the hackathon: IBM Bob IDE task session summaries from **every** team member.

After each Bob task:

1. In Bob's chat, open the task history, select the task and click its header to show the consumption summary.
2. Screenshot it as a PNG named `north_taskXX_<yourname>_<description>_summary.png`,
   e.g. `north_task03_saman_linty_review_cart_total_summary.png`.
3. Click **Export task history** and save the `.md` file here with the same base name.
4. Check both files for API keys, tokens or personal info before committing.
5. Commit from your own GitHub account.

01 · The problem

Code review is slow, manual, and the tests get skipped.

⏳

Reviews eat hours

A reviewer reads every line, spots the bug, explains it, and waits for a fix. It happens on every pull request.

🧪

Tests get skipped

Writing regression tests is the first step cut under deadline pressure, so the same bug comes back.

🤷

AI fixes aren't trusted

Assistants suggest fixes, but without proof a human still has to verify every change by hand.

03 · IBM Bob is the engine

Linty ships as a Bob configuration.

🧹 Custom modes

An orchestrator plus four specialist modes. Each can only write its own output file (fileRegex): permissions as governance.

🧩 Subtasks

The orchestrator hands each stage to a specialist as a separate Bob subtask, a genuine multi-agent pipeline.

⚡ Slash command

/linty-review <file> runs everything: start, 4 agents, finalize, summary.

🛡️ Rules + .bobignore

Shared guardrails for every mode: no secrets, never touch the ground truth, report measured numbers only.
